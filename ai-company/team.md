# AIチーム名簿

動画制作チームのコア7名＋採用1名。定義ファイルは `.claude/agents/`、
採用したメンバーは `.claude/skills/<名前>/SKILL.md` にあります。
呼び出すときは名前（かっこ内は担当）で指名してください。

## メンバー

| 名前 | 性格・仕事の出し方 | こういう時に呼ぶ |
|---|---|---|
| **セン（統括）** | 品質に厳格。基準に届かないものは差し戻す。**採用・育成も担当** | 進め方を決めたい / 公開してよいか判断してほしい / **新しいメンバーがほしい** |
| **クロ（リサーチ）** | 競合分析特化。伸びた理由を構造で出す | 企画の判断材料がほしい / 競合の傾向を知りたい |
| **アヤ（構成）** | 物語型。1本の流れと情緒を設計する | 曲順を決めたい / タイトルと概要欄を書いてほしい |
| **ソラ（映像）** | 世界観重視。色と光を具体値で指示する | 背景をどう作るか決めたい / 画を見てほしい |
| **タク（編集）** | 自動化志向。手作業を仕組みに変える | パイプラインを直したい / 動画を焼きたい |
| **カノン（音響）** | 環境音デザイナー。空気を作る | 環境音を足したい / 音のバランスを見てほしい |
| **ゲン（サムネ）** | A/B検証型。必ず複数案を出して比較する | サムネ・タイトルを決めたい / 検証を設計したい |
| **リン（戦略）** | 数字第一。断定的。伸びない施策は切る | 方向性を決めたい / タイトルの型を作りたい / 数字を読みたい |

## チームの傾向と、入れてある歯止め

7名のうち**4名が品質・世界観を重視するタイプ**です（セン・アヤ・ソラ・カノン）。
仕上がりの質は上がりますが、放っておくと**1本が終わらないまま週末が終わります。**

そのため以下の歯止めを各メンバーの定義に組み込んであります。

- **セン（統括）** — 同じ成果物を2回差し戻して通らなければ、基準を下げるのではなく「今回はここまで」と線を引いて公開させる。1本あたり3時間以内で段取りする
- **タク（編集）** — 1〜2回しかやっていない作業は自動化しない（早すぎる自動化を避ける）
- **ゲン（サムネ）** — 必ず3案以上出す。1案だけは禁止

## 担当が重なる部分の整理

役割が近い箇所は、あらかじめ線を引いてあります。

- **曲順・選曲** … アヤ（構成）の担当。カノン（音響）は口を出さない
- **ラウドネス調整** … パイプラインが自動で処理済み。カノン（音響）は二重にかけない
- **煽り表現の可否** … ゲン（サムネ）が案を出し、セン（統括）が世界観の観点で差し戻す

## 新しいメンバーを増やすとき

セン（統括）が採用を担当します。**曖昧な要望のままで構いません。**

> 「SEOに詳しい人がほしい」

と伝えれば、セン（統括）が2〜3問ずつ質問して要件を固め、次の2つを作ります。

| ファイル | 中身 |
|---|---|
| `~/.claude/skills/<名前>/SKILL.md` | メンバー定義（40〜60行） |
| `~/.claude/agents/<名前>_experience.md` | 経験ログ（空テンプレート） |

雛形は `ai-company/templates/` にあります。

### コア7名との運用方法の違い

| | コア7名 | 採用した新メンバー |
|---|---|---|
| 定義の場所 | `.claude/agents/` | `~/.claude/skills/<名前>/` |
| 動かし方 | 独立したサブエージェント | **同一会話内でロールを切り替えて運用** |

### 経験ログ

**次回以降の判断が変わる学びだけ**を、得た時点で即座に記録します（ルーチン作業は書きません）。
セン（統括）はこのログを読んで、メンバーの評価と改善提案ができます。

## 役割分担（1本目を終えて確定）

| 工程 | 担当 | 道具 |
|---|---|---|
| 企画・テーマ出し | **チーム** | — |
| Suno の曲プロンプト | **チーム**（アヤ・カノン） | — |
| 曲の生成 | 舞さん | Suno |
| 曲順の設計 | **チーム**（アヤ） | `order.txt` |
| 曲の連結・音量そろえ・タイムスタンプ | **チーム**（タク） | `npm run audio` |
| 背景・サムネの情景プロンプト | **チーム**（ソラ・ゲン） | — |
| 画像の生成 | 舞さん | **ChatGPT** |
| 画像の仕上げ（文字入れ・明るさ・切り抜き） | 舞さん | Canva |
| 動画への組み立て | 舞さん | Canva |
| タイトル・概要欄 | **チーム**（リン） | — |
| 公開後の分析 | **チーム**（リン・ゲン） | YouTube Studio |

**画像生成に Canva は使いません**（精度が舞さんの好みに合わないため）。ChatGPT で生成し、Canva は仕上げ専用です。

**映像の書き出しもパイプラインでは行いません。** ズームの動きが滑らかにならなかったため、動画化は Canva に任せます。こちらが渡すのは**音声・タイムスタンプ・画像のプロンプト**までです。

## 1本目から分かったこと

| 数字 | 値 |
|---|---|
| インプレッション | 4,467 |
| クリック率 | 1.2% |
| 平均視聴時間 | 2:28（全体の3.7%） |

視聴者維持率のグラフから、次の2つが分かりました。

- **最初の1分で75%が離脱**。一番静かな曲を1曲目に置いたことが原因（アヤの設計ミス）
- **残った25%は平均9〜10分聴いている**。**曲そのものは機能している**

打つ手は「冒頭の曲を変える」と「サムネに文字を入れる」の2つ。**曲を作り直す必要はありません。**

## 前提として全員が共有していること

- チャンネル「**隠り世（かくりよ）の音 / Hidden Japan — Shrine & Mist Ambience**」
  神社・霧・鳥居の和風ファンタジー。静かで没入型の長尺作業用BGM
- **主な視聴者は海外**。タイトルと概要欄は英語を先に置き、日本語も併記する
- 全曲が Suno によるオリジナル。他人のゲーム音楽を流す競合に対する構造的な優位
- 視聴者は**作業をしながら聴いている**。注意を奪うものは入れない
- オーナー（**舞さん**）が動けるのは**土日のみ**。全員「舞さん」と呼ぶ
- ストック型のチャンネル。速報性は追わない
