# 作業用BGM動画 生成パイプライン

Suno で作った曲をフォルダに放り込んで `npm run audio` を叩くと、
**クロスフェードで繋がった長尺の音声**と**概要欄に貼るタイムスタンプ**が出てきます。
動画への組み立ては Canva で行います。

映像つきで書き出す `npm run build` も残してありますが、ゆっくりズームの動きが
滑らかにならなかったため、通常は使いません。

このパイプラインはリポジトリの `ai-company/` 配下にあります。

## 準備（最初の1回だけ）

```bash
cd ai-company
npm install
```

ffmpeg は npm パッケージに同梱されているので、**別途インストールする必要はありません。**
必要なのは Node.js だけです（v18 以上）。

## 使い方

1. `ai-company/assets/music/` に Suno の曲を置く（mp3 / wav / m4a / flac / ogg）
2. `ai-company/assets/background/` に背景を置く
   - **画像**（png / jpg / webp）… 静止画の背景になります
   - **動画**（mp4 / mov / webm）… Kling などで作った数秒の素材を置くと、
     **順再生と逆再生をつないで継ぎ目を消し**、音声の長さぶん繰り返します
3. **曲順を確定する**（任意）

`order.txt` に並べたい順で曲名を書き、実行します。

```bash
npm run reorder
```

ファイル名が `01 - 曲名.mp3` の形に振り直されます。行頭に `#` を付けた曲は使われず、
`assets/music/_unused/` に移動します（**消えません**）。
名前の打ち間違いや重複があった場合は、**何も変更せずに**中断します。

4. **書き出す前に確認する**（数秒で終わります）

```bash
npm run check
```

曲数・各曲の長さ・合計時間・概要欄の位置に加えて、**背景画像の寸法と縦横比**も確認できます。
読めないファイルや、解像度の足りない背景があればここで分かります。
狙いの尺（`config.json` の `targetMinutes`）とずれていたら、ちょうど良い曲数も教えてくれます。

5. サムネイルを作る

```bash
npm run thumbnail
```

背景画像から `thumbnail.jpg`（1280×720）を作ります。YouTube の上限である
2MB に収まるよう、必要なら画質を自動で調整します。

6. 書き出す

```bash
npm run build
```

映像は自分で作りたい（Canva などを使う）場合は、音声だけを書き出せます。

```bash
npm run audio
```

`audio.mp3` と `tracklist.txt` だけが出ます。曲の連結・音量そろえ・タイムスタンプは
`build` とまったく同じ処理なので、結果も同じです。MP3 にしているのは、
どのソフトでも読み込めるためです（1時間で 110MB 程度になります）。

リポジトリのルートからでも実行できます（パスは自動で解決されます）。

```bash
node ai-company/build.js
```

`ai-company/out/20260824-1430/` のような日時フォルダに、こう出てきます。

| ファイル | 中身 |
|---|---|
| `video.mp4` | アップロードする動画本体 |
| `tracklist.txt` | 概要欄にそのまま貼れるタイムスタンプ |
| `audio.m4a` | 繋いだ音声（作り直すとき再利用できる） |
| `loop.mp4` | 背景のズームループ（同上） |

## ショート動画を作る

```bash
npm run short
```

縦1080×1920のショートが `out/日時-short/` に出ます。素材は長尺と同じ `assets/` を使います。

設定は `config.json` の `short`。

| 項目 | 意味 |
|---|---|
| `track` | 使う曲のファイル名。空なら最初の1曲 |
| `startSeconds` | 曲のどこから切り出すか |
| `durationSeconds` | 長さ。45秒前後が目安 |
| `mode` | `crop`（画面いっぱいに切り出す）/ `blur`（上下をぼかしで埋める） |
| `cropX` | `crop` のとき、横のどこを使うか。`0`=左端 `0.5`=中央 `1`=右端 |
| `fadeSeconds` | 冒頭と末尾の音のフェード。ショートは繰り返し再生されるので必須 |

**`cropX` は画ごとに変わります。** 16:9から9:16を切り出すと**横の3分の1しか残らない**ため、
見せたいものがどこにあるかで決めてください。

## 設定

いじるのは `ai-company/config.json` だけです。

| 項目 | 意味 |
|---|---|
| `targetMinutes` | 狙う尺（分）。`npm run check` がこれと比べて過不足を教えてくれる |
| `shuffle` | `true` にすると曲順をランダムにする。ファイル名順でよければ `false` |
| `crossfadeSeconds` | 曲の重なり秒数。長いほど繋ぎ目が滑らかになる |
| `loudnessNormalize` | **曲ごとに音量を測って -14 LUFS に揃える。** 基本は `true` のまま |
| `video.loopSeconds` | 背景ループの長さ。長いほど繰り返し感が減るが、書き出しも遅くなる |
| `video.pingPong` | 背景が動画のとき、順＋逆でつないで継ぎ目を消す。`false` でそのまま繰り返す |
| `video.zoomAmount` | ズームの強さ。**`0` で完全な静止画**（既定値）。`0.08` にすると 8% ゆっくり拡大縮小する |

## 仕組み（なぜ速いのか）

1時間の映像をまるごとエンコードすると数十分かかります。
このパイプラインは **60秒の「継ぎ目のないループ」を1本だけ作り、それを無変換で繰り返して**
音声の長さに合わせています。そのため動画が何時間になっても書き出し時間はほぼ一定です。

ループの継ぎ目が見えないのは、ズーム倍率を cos カーブで
`1 → 1.08 → 1` と往復させ、先頭と末尾の絵を一致させているためです。

ズームには `perspective` フィルタを使っています。よく使われる `zoompan` は
拡大位置を1ピクセル単位でしか動かせず、60秒で8%というごく遅い動きでは
「何十フレームも止まって突然1ピクセル飛ぶ」というカクついた動きになります
（実測で全フレームの53%が静止）。`perspective` は小数の座標を扱えるため、
同じ条件で静止フレームは1%まで下がります。

## ファイル構成

```
ai-company/
  order.txt         曲順の指定
  reorder.js        order.txt どおりにファイル名を振り直す
  audio.js          音声だけを書き出す（映像は作らない）
  thumbnail.js      背景画像からサムネイルを作る
  check.js          書き出す前の確認（曲数・尺・読めないファイル）
  build.js          実行の入口。1〜4 の手順をこの順に呼ぶだけ
  config.json       設定
  src/ffmpeg.js     ffmpeg / ffprobe を動かすヘルパー
  src/playlist.js   曲を集める・長さを測る・タイムスタンプを計算する
  src/loudness.js   曲ごとの音量を測る
  src/audio.js      音量を揃えてからクロスフェードで繋ぐ
  src/video.js      ズームループを作る・音声と合成する
  assets/music/     Suno の曲を置く場所
  assets/background/ 背景画像を置く場所
  out/              書き出し先
```
