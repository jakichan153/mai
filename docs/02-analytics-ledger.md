## 3. 最優先の実測タスク（オーナー作業）

YouTube Studio → アナリティクスから、以下を埋めてください。これが埋まらないと全ての判断が推測になります。

### タスクA: 4本目の失速原因【実測完了 2026-09-20】

| 流入元 | 動画1（636回） | 動画4（26回） | 絶対数の差 |
|---|---|---|---|
| ブラウジング機能 | 70% ≒ **445回** | 15% ≒ **4回** | **約1/110** |
| 関連動画 | 22% ≒ 140回 | 69% ≒ 18回 | 約1/8 |

**結論:**
1. 崩壊したのは関連動画ではなく **ブラウジング（ホーム推薦）**。445回 → 4回。
2. 動画4の「関連69%」は母数26回の内訳にすぎず、実体は自チャンネル他3本からの内部循環。**新規リーチはほぼゼロ**。
3. 動画1のブラウジング70%は健全値。**このチャンネルは一度、推薦エンジンの点火に成功している。**

**→ 本チャンネルは「検索型」ではなく「ブラウジング（推薦）主導型」と確定。SEO優先度を下げ、投稿頻度と視聴者層の一貫性を最優先に置く。**

### タスクA-2: ブラウジング停止の原因【実測完了 2026-09-20】

| | インプレッション | CTR | クリック数 | 実再生 |
|---|---|---|---|---|
| 動画1 | 14,000 | 3.8% | ≒532 | 636 |
| 動画4 | 1,022 | 1.8% | ≒18 | 26 |
| 差 | **13.7倍** | **2.1倍** | — | 24.5倍 |

13.7 × 2.1 = 28.8 ≒ 再生数差24.5倍。データに矛盾なし。

**確定した因果（前回の「X vs Y」の2択は誤り。両者は直列関係だった）:**
```
サムネ・タイトルを変更
 → 初回テスト配信でCTR 1.8%（拡大ライン2%割れ）
 → YouTubeが配信拡大を打ち切り
 → インプレッションが1,022で停止
 → 26回再生
```
インプレッション1,022は **原因ではなく結果**。引き金はパッケージ（サムネ・タイトル）で確定。

「サムネが弱かった」のか「合わない層に配られた」のかは本データでは分離不能。ただし**打ち手は同一**（勝ちパッケージ＝1人・没入構図 ＋「洋楽プレイリスト」へ回帰）のため、これ以上の切り分けは行わない。

### 【新・最重要課題】CTR 3.8% がチャンネル全体の天井

動画1は成功作だが、CTR 3.8% は成長律速要因そのもの。

| CTR | 14,000impからの再生 |
|---|---|
| 現状 3.8% | 532 |
| 目標 6.0% | **840（+58%）** |

CTR改善は2段階で複利に効く: ①同一impからの再生増 ②高CTRはimp配信量自体を増やす。

**収益化逆算への影響（必要再生20,000回）**
- CTR 3.8% のまま → 約 **53万** インプレッションが必要
- CTR 6.0% なら → 約 **33万** インプレッションで到達

→ **CTR改善は投稿本数1.5倍より費用対効果が高い。第1期の最優先施策とする。**

## 4. 判断基準（この数字が出たらこう動く）

| 指標 | 水準 | アクション |
|---|---|---|
| CTR | **< 2.0%** | **推薦打ち切りライン**（動画4=1.8%がここ）。即サムネ差し替え |
| CTR | 2.0〜3.5% | 配信が拡大しない。改訂必須 |
| CTR | 3.5〜4.5% | 現ベースライン（動画1=3.8%）。改善余地大 |
| CTR | **> 5.5%** | 推薦が拡大し始める水準。その構図を全シリーズへ横展開 |
| 平均視聴率 | < 15% | 曲順・音量差を疑う。music-curator が冒頭3曲を再設計 |
| 平均視聴時間 | < 8分 | 尺を40分台に短縮して1本あたりの完走率を上げる |
| 主要流入が「ブラウジング」 | **本チャンネルはこれ** | ①投稿頻度 ②視聴者層の一貫性 ③CTR の順に効く。SEOは優先度を下げる |
| ブラウジングの**絶対数**が前作比で半減 | — | 視聴者層の紐付けが切れた疑い。タイトル語彙とサムネ系統を直前の成功作に戻す |
| 主要流入が「関連動画」かつ母数が小さい | — | 自チャンネル内の循環＝新規リーチ0。ブラウジング復帰を最優先課題に昇格 |
| 主要流入が「検索」 | — | タイトルSEOが効いている。キーワードを固定 |
| 登録転換率 | < 0.2% | 登録導線（エンドスクリーン/中間カード/冒頭テロップ）を最優先で改修 |
