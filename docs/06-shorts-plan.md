## 0. 先に読む（前提の修正3点）

### 0.1 「約79,000再生」は Shorts にそのまま当てはまらない
1.26%（8人/636回）は「平均9分8秒聴いた長尺視聴者」の転換率。Shorts 視聴者は数秒で判断するため、転換率は一桁以上低い可能性が高い（未計測。本計画の最初の測定対象）。

| Shorts の登録転換率（仮定） | +992人（8→1,000）に必要な Shorts 再生 |
|---|---|
| 1.26%（長尺と同等・楽観） | 約79,000 |
| 0.5% | 約198,000 |
| 0.3% | 約331,000 |
| 0.1% | 約992,000 |

→ 30日では1,000人に届かない。**30日の目的は「転換率と配信量の実測」と「長尺が再び配信される状態の回復」**。

### 0.2 Shorts の視聴時間は 4,000h に入らない
YPP の通常ルートは「1,000人 + 長尺の公開視聴時間4,000h（12か月）」。Shorts 視聴は時間に算入されない（Shorts経由は「1,000人 + Shorts 1,000万回/90日」の別ルートで非現実的）。
→ **Shorts = 登録者と配信量の回復担当。再生時間は長尺で約26,000再生が別途必要**。役割分担は変わらない。

### 0.3 Shorts の説明欄・コメントのURLはクリックできない（2023年8月〜。2026年の現状は一次情報で未確認）
「固定コメントにURL」は効かない前提で導線を組む（§3）。
- Web検索で「2027-02-01 に YPP 基準が 8,000h / 2,000万回へ引き上げ」という記述を1件見つけたが、**Google公式での裏取りができていない**。事実なら期限が変わる。音城さん側で YouTube ヘルプの公式ページを確認してほしい。

出典: [YPP要件 2026（AIR Media-Tech）](https://air.io/en/monetization/youtube-partner-program-requirements-2026-the-complete-guide) / [Shorts リンク無効化（Tubefilter）](https://tubefilter.com/2023/08/10/youtube-shorts-comments-spam/)

## 1. Shorts の基本設計

### 1.1 1本の構成

| 項目 | 設計 |
|---|---|
| 尺 | **8小節 = 約22〜27秒**（72〜88bpm。4拍×8小節）。曲として完結し、ループしても切れ目が不自然にならない。月1〜3本は **4小節（約11〜13秒）** のループ型を混ぜる |
| 音 | **0.0秒から音が鳴る。** 切り出しは「サビ頭」または「歌い出し（最初のボーカルが入る拍頭）」。頭のフェードインなし（最大0.1秒）。末尾のみ0.4秒フェードアウト |
| **曲頭スタート禁止** | #01 の実測で **イントロ2秒・歌い出し11秒**。曲頭から切ると22秒のうち約半分が歌なしになり、フィードでは遅すぎる。必須条件: ①**0.0秒の時点で歌 or 主旋律が既に鳴っている** ②前奏・ノイズ・ヒス・無音だけの区間を1秒も残さない ③ブレス/ピックアップ付きの歌い出しは、最大0.3秒手前から入れてよい（拍頭に合わせて切る） ④インスト曲は「主旋律が最も明瞭な最初の8小節」の拍頭から |
| 冒頭1秒 | ロゴ・無音・前口上なし。**0.0秒のフレームで「絵 + 主テロップ + 曲名」がすべて表示済み**（フィードのプレビュー静止画でも内容が伝わる） |
| 画面構成 | 縦9:16（1080×1920）。§1.2 の3層構成 |
| テロップ | あり（必須）。0〜8秒 主テロップ / 8〜16秒 副テロップ / 常時 曲名 / 末尾2.5秒 導線文言 |
| 曲名表示 | 常時 `♪ Golden Hour Window` のように英語曲名を小さく表示（D2: オリジナル曲名の明示＝透明性） |

### 1.2 縦9:16 の画作り（横長素材しかない制約の解決）

素材は 1280×720（サムネ）と 1080p以下の16:9ループ映像。9:16に**全面クロップすると 2.7倍に引き伸ばされて劣化する**ため禁止。

**標準レイアウト（3層）**

```
y=0     ┌──────────────┐
        │ 上部 安全域外（UIが重なる）  │
y=230   │ Playlist / Afternoon #02   │ ← ブランド刻印（2行・細セリフ・#3A3A6E・小。全Short同位置。不変）
y=420   │ ぼかし背景（同素材を高さ全面に拡大→ぼかし→明度+）│
y=520   │ ┌────────────┐ │
        │ │ 主画（1080幅・構図 W/M/S/D）│ │ ← 1080×608〜1080×1080
y=1130+ │ └────────────┘ │
y=1180  │ ♪ 曲名（小）          舞（署名）│ ← 同一行。曲名は左、「舞」は右端（右余白150px内）
y=1260  │ 主テロップ（1〜2行）        │ ← 右余白150px・下はy=1450まで
y=1450  │ （ここから下は Shorts のUIが重なる：何も置かない）│
y=1920  └──────────────┘
```

- 背景: 同じ素材を拡大してぼかし、**明度を上げてクリーム色を30%重ねる**。規約 §2.1.5.5「濃色文字で明度勝ち」を成立させるため。文字色は `#3A3A6E`（白文字にする場合は濃色ドロップシャドウ必須）。
- 構図コード（CapCutのスケール/位置だけで作る。Canva加工は不要）:

| コード | 構図 | 拡大率 |
|---|---|---|
| W | 全景（16:9を幅1080に収める） | 100% |
| M | 人物寄り（窓際の人物を中心にトリミング） | **最大140%**（これ以上は粗くなる） |
| S | 窓外・背景のみ（人物を外す。街並み・雲・光） | 130〜140% |
| D | ディテール（窓枠・座席・手元・光の筋） | 140% |

- **チャンネル名「舞」の反映方針（`docs/03-packaging-rules.md` §2.1.5.5 / A3 との整合）**
  - **刻印の2行は変更しない。** `Playlist`（基準サイズ）の直下に `Afternoon #02`（`Playlist` の35〜40%）、細めセリフ体・タイトルケース・`#3A3A6E`・字間やや広め、位置はサムネと同じ「左上」の思想。サムネとShortsで同じロックアップにすることがブランド資産になるため、刻印に「舞」を足して3行にはしない（サムネ規約A3「文字は PLAYLIST + シリーズ名のみ」とも矛盾させない）。
  - 「舞」は刻印とは**別要素の署名**として、主画下の曲名行の右端に置く。サイズは曲名行の1.0〜1.2倍（`Playlist` より小さく、主役にしない）、同じ細セリフ体・`#3A3A6E`・不透明度80%。役割の整理: 「Playlist / Afternoon」= 何の作品か、「舞」= 誰の（どのチャンネルの）作品か。
  - 末尾導線（§3.2）の1行目の頭にも「舞」を入れる。SNS版（§6）の末尾も「舞」を主語にする。
  - 理由: Shorts UI には @ハンドルが出るが、TikTok / Reels では表記が変わりうる。画面内に名前が残ると、再投稿・共有されても出所が伝わる。単漢字なので小さくても形が崩れにくい。
  - 確認: スマホ実機の縮小表示で「舞」が判別できるか（A4）。判別しにくければサイズを1.2倍に上げる（Playlistを超えない範囲）。サムネ・バナー側への展開は art-director の判断事項（本書は変更しない）。
- 動き: **L**=ループ映像をそのまま（速度0.8〜1.0倍）/ **Z**=静止画に100→112%のゆっくりズーム / **P**=静止画のゆっくりパン。
- 色温度: 昼→夕に沿って 明 / 標準 / 琥珀 / 夕暮れ をCapCutの色温度スライダーで付ける。**曲の役割（#02は88→72bpmで午後→夕暮れへ下降）に対応させる**。意味のある変化として画に差が出る。
- 任意の上位策: Canva Pro の「マジックエキスパンド」で16:9を縦に拡張し、全画面の絵にする。初回に2素材だけ試し、破綻なければ採用（失敗してもぼかし方式で運用可能）。
- **#01 の画像・ループ映像は、音源が使えなくなっても画としては使える。** 音は #02、画は #01/#02 の混在になるが、同じ AFTERNOON の世界（電車の窓・午後の光）なので違和感はない。刻印の番号は**音源の出典**（#02）に固定する。画の種類が増えることは、2回使用する曲の見た目を変える手段にもなる。

**D1（静止画だけの動画を避ける）との整合**: 20本中 **10本は動画素材（ループ）** を主画にする（§2）。静止画回も動きとテロップの切り替えを必ず入れる。

### 1.3 音が出ていなくても伝わる状態
1. 0.0秒から画面に **用途が分かる語**（作業用BGM／勉強用BGM／歌なし）を副テロップか主テロップに含める。
2. 主テロップ（情景の一行）は8秒ごとに切り替え、**音がなくても読み進める動き**を作る。
3. 曲名・シリーズ名を常時表示し、「何の動画か」を無音でも理解できるようにする。
4. 末尾の導線は文字だけで完結する。

### 1.4 テロップ仕様（規約 §2.1.5.5 準拠）
- 書体: 細めのセリフ体（B4で確定。全Shortsで同一フォント）/ 色 `#3A3A6E` / 字間やや広め / 煽り語・感嘆符・絵文字なし。
- 1行18字以内、最大2行、右余白150px、下端y=1450まで。
- 型は4種を回す: **[情景]**（場面を一行）／**[歌詞]**（Suno歌詞から英語1行。副テロップ）／**[問い]**（コメントを促す）／**[時刻]**（「午後3時。」）。インスト回の副テロップは **[用途]**（「歌なし・作業用BGM」）で、無音でも用途が伝わるようにする。
- 刻印の番号（#NN）は切り抜き元の長尺の番号。標準形（#02のみ）では常に `#02`。

## 2. 30日企画表（#02 の15曲のみ）

### 2.0 運用ルール
- Day = 暦日（10/9 = Day1）。土日は投稿しない。D29（11/6 金）は予備 R1 を使う。**投稿時刻は毎回 18:00 固定**（学生・20代の帰宅/移動帯の仮説。変えるのは判定1の後）。
- **日付がずれた場合（2026-10-12 時点の扱い）**: 投稿#の**順序を維持して日付だけ後ろへずらす**。曜日枠より順序を優先するが、ずれて枠と合わない行（例: インスト回が月曜に来る）は**同じ枠属性の行同士で入れ替えてよい**。判定日は日付でなく「P6 の7日後以降の日曜」「P16 の7日後以降の日曜」で読み替える。1本でも投稿が空いた日は予備案（R）で埋める。
- **曜日固定の枠**（#02単独。継続して見る理由を作る / `00-strategy.md` §6-1）:

| 曜日 | 枠 | 使う曲 |
|---|---|---|
| 月 | 午後のはじまり（つかみ曲） | 明るめの有声曲（#1〜#3、#9 の2回目） |
| 火 | 電車の午後 | 有声曲（#3、#9、#12 ×2回） |
| 水 | 歌のない午後 | インスト #4・#8・#11 と、ほぼインストの #15（`afternoon-02-music.md` の構成どおり） |
| 木 | 最新長尺枠 | #03 以降が公開済みならその週の新作の曲。未公開の間は #02 の有声曲（#5・#10・#7・#14） |
| 金 | 問いの日 | 有声曲（#1・#6・#2 区間B・#13）＋[問い]テロップ |

- **曲の使い方**: 15曲 × 20本。単発10曲（#4・#5・#6・#7・#8・#10・#11・#13・#14・#15）、**2回使用5曲**（#1・#2・#3・#9・#12）。
- **2回使用のルール**:
  1. 1回目 = **サビ頭**（フック）、2回目 = **歌い出し**（最初のボーカルが入る拍頭。曲頭≈0:11を想定、要耳確認）。
  2. 2区間は**8小節分以上離れ、重ならない**（1回目の終了秒 < 2回目の開始秒、または逆）。サビが早く入る曲（曲頭≈0:33より前）は、2回目を「2番の歌い出し／2回目のサビ頭」にする。
  3. 同じ曲の2本は**5投稿以上あける**。画・テロップの型・色温度も変える。
  4. 3回目の区間は予備（R）に回す。
- **サビが明確でない静かな曲**は「サビ頭」を「最も耳に残る最初のボーカルフレーズ」と読み替える。
- 画コード: `I1`=#01サムネ文字なし版 / `I2`=#02サムネ文字なし版（頬杖・目を閉じる）/ `V1`=#01ループ / `V2`=#02ループ（8秒）。`V1`が無い場合は `I1`+Z に置換。
- **使用箇所の秒数メモ（サビ頭・歌い出しの開始秒）はオーナーが事前に1回だけ取る**（§4-B）。

## 4. 制作手順（CapCut無料版・スマホ・15分以内）

### 4-A. 初回のみ：テンプレ `SHORTS_TPL` の作成（約60分 / 一度だけ）
1. 新規プロジェクト → 比率 9:16 → 書き出し設定 1080p / 30fps。
2. 動画トラックに仮のループ映像を置く（背景用）→ 複製して「画面全面拡大 + ぼかし + 明るさ上げ + クリーム色の半透明レイヤー30%」にする（ぼかし層）。
3. 同じ素材をもう1つ重ね、幅1080・中央配置（主画層）。**ゆっくりズーム 100→112% のキーフレームを入れておく**（静止画回の既定動作）。
4. テキストを作る（フォントはB4で確定した細明朝系。色 `#3A3A6E`、字間広め）:
   - 刻印「Playlist」（基準）＋直下「Afternoon #02」（35〜40%）の2行（上部、全Short同位置、小）
   - 曲名「♪ Song Title」（主画下の左、常時）
   - **署名「舞」**（同じ行の右端、曲名の1.0〜1.2倍、不透明度80%、常時）
   - 主テロップ（0〜8秒）／副テロップ（8〜16秒）
   - 導線 E1・E2・E3（末尾2.5秒、重ねておく。使うものだけ残す。1行目の頭は「舞」）
   - SNS版用の末尾文言 S1（「舞　全編はYouTubeで」/「プロフィールのリンクから」）
5. オーディオトラックを空にして保存。名前 `SHORTS_TPL`。
6. 書き出し設定で **CapCutのデフォルトエンディング（末尾の宣伝クリップ）をOFF**。
7. テストとして1本通しで作り、スマホ実機で縮小表示 → 文字が読めるか（A4）、「舞」が判別できるか、UIに文字が重ならないかを確認。

### 4-B. 週1回：切り出し位置メモ（日曜 約15分）
翌週5曲分を一括で。Suno曲ページ（または長尺の該当曲）を再生し、**歌い出しの開始秒とサビ頭の開始秒の両方**と、BPMから算出した8小節の終了秒をメモ（例：`#1 / 歌い出し 0:11 / サビ頭 0:41 / 8小節=約22s`）。2回使用の曲は2区間分を決めておく。インストは主旋律が鳴っている最初の拍頭を探す。1曲3分以内。**平日の15分に曲探しを持ち込まない。**

## 5. 計測設計

### 5.1 記録（Shortsごと。シート1行）
`投稿# / 日付 / 元曲 / 区間（A・B・C）/ 画コード / テロップ型 / 秒数 / 24h再生 / 48h再生 / 7日再生 / 視聴継続率（視聴 vs スワイプ）/ 平均視聴率 / 7日登録増`
取得: Studio → コンテンツ → Shorts → 各動画のアナリティクス。**48h・7日の2回**（`02-analytics-ledger.md` の48h/7d/28dルールのうち、Shortsは28日を省略。20本×3回は運用に乗らない）。
**区間（A/B）を記録する理由**: 2回使用の曲で、1回目と2回目の反応差（聴感上の重複の影響）を見るため。

### 5.2 頻度

| 頻度 | 見るもの | 所要 | 判断してよいこと |
|---|---|---|---|
| 毎日 | 前日投稿の24h再生を転記するだけ | 2分 | 判断しない（母数不足） |
| 毎週日曜 | 48h/7日の確定分、中央値、登録増、長尺のimp | 15分 | 来週の型の微調整（1レバーのみ） |
| **Day10（10/18）** | 技術チェック | 10分 | 「配信されているか」だけ見る |
| **Day17（10/25）判定1** | 7日確定の6本（P1〜P6） | 30分 | 継続/改修/切替 |
| **Day31（11/8）判定2** | 7日確定の16本（P1〜P16） | 30分 | 拡大/継続/改修/撤退 |

日付がずれた場合は §2.0 の読み替え（P6 / P16 の7日後以降の日曜）に従う。
Day10 の技術チェック: 6本とも48h再生が50未満なら、コンテンツの前に設定を疑う（Shortsとして認識されているか＝9:16・3分以内／「子ども向け」設定／制限・著作権申立て／非公開・限定公開の誤設定）。

### 5.3 判定基準（**初期値は仮説**。Day17の実測中央値で再校正する）

**母数ルール（`CLAUDE.md` 作業原則1「n<100 から結論を出さない」への対応）**
- 比率の指標（視聴継続率・平均視聴率・登録転換率）は、**1本の再生が100未満なら、その1本の比率では判断しない。** 判定1・2では複数本を合算（プール）した再生数で見る。
- 登録転換率は、**プール再生数が1,000未満なら比率を見ず**、登録増の絶対数だけで判断する（登録増が1桁なら「転換率は測定不能」と記録する）。
- 判定1（n=6本）の根拠は粗い。判定1で動かしてよいのは**1レバーの変更まで**であり、撤退は判定2（n=16本）でのみ行う。
- 単発の1本（バズ・不発）で型を変えない。中央値と、上位1本を除いた合計の両方で見る。

#### 判定1（Day17 / n=6）

## 6. 外部SNS（TikTok / Instagram Reels）

- **同じ素材をそのまま使う。追加制作ゼロ。** 例外は末尾2.5秒だけ（SNS版 S1「舞　全編はYouTubeで」）に差し替えて書き出す（§4-C 手順8。1分以内）。「YouTubeで登録」の文言は他プラットフォームでは意味がないため。画面内の署名「舞」はそのまま残す（出所が伝わる）。
- CapCutのデフォルトエンディング（宣伝クリップ）は**OFF**にして書き出す。YouTubeやTikTokのロゴ入りに保存し直した動画は使わない（透かし入りは配信が弱まる）。必ず元の書き出しファイルをアップロードする。
- 投稿は YouTube投稿の直後、手動。キャプションは主テロップの一文 + 3〜4個のタグ。URLは貼らない（プロフィールのリンクに集約）。
- 各プラットフォームの **AI生成ラベル**がある場合はONにする（D4: AI制作を隠さない）。
- アカウント名・アイコンは YouTube（舞）と統一。プロフィールには「舞｜午後の洋楽プレイリスト／全編は YouTube で」と日本語1行 + YouTubeへのリンク。
- 目的は「外部サイト経由の登録」ではなく、**①長尺への直接流入（検索/ブラウジング以外の初動）②反応の良い型の早期発見**。これらSNSの反応は、Shortsの型の比較材料として週次で見る（再生数のみ。分析工数は増やさない）。
- 制作は毎日、SNS投稿は**各2分**。時間が足りない日は SNS を飛ばし、**YouTubeを優先**する。

## 8. 条件付き：#01 マスター音源が残っていた場合（B1 が「ある」）

### 8.1 前提と価値
- #01（46:33）は **平均視聴時間9分8秒・維持率19.6%・CTR3.8%・YouTubeの評価「通常を上回る」** の実証済み音源。使えるなら、2回使用が必要な #02 の弱点（聴感上の重複）を消せる。

- さらに予備案（R2〜R9）の一部を #01 の別区間に置き換えてストックを増やせる。

### 8.3 マスターのどこを切り抜くか（指針）
1. **前半を優先する。** 平均視聴時間が9:08なので、視聴者が実際に聴いた音は冒頭〜約9分（1〜3曲目付近）に集中している。実証済みの区間から使う。
2. **維持率グラフ（B8）の山を見る。** 再視聴で持ち上がっている区間、維持率の落ちが緩やかな区間が「聴かれている音」。その区間のボーカルが入る拍頭から切る。
3. **曲境界は波形で探す。** 約3分ごとの音量の谷とクロスフェード（2〜3秒）。**クロスフェード中（2曲が混ざる区間）は絶対に切り抜かない。** 境界の2〜3秒後から数える。
4. **歌い出し = 曲境界 + 約11秒**（#01 実測。曲ごとに多少ずれる）。0.0秒で歌が鳴るよう、歌い出しの拍頭（最大0.3秒手前）から切る。曲頭からは切らない（§1.1）。
5. **インストの間奏・曲間の溜めは避ける。** 終盤（フェードアウトする最終曲付近）も避ける。
6. 8小節の秒数は BPM から計算する。BPM は **タップテンポ**（任意の無料BPMアプリで30秒）で実測する。分からなければ歌い出しから次のフレーズの切れ目までを目安に切り、22〜27秒に収める。
7. 切り出しは1本のマスター（mp3/wav）から CapCut で行う。再エンコードによる劣化は聴感上問題ないレベル。**マスターが mp4（映像付き）の場合は音声のみ抽出して使う**（映像は縦構図に合わないため）。

### 8.4 曲名テロップが出せないときの代替表示

`♪ 曲名` の行（常時表示）を以下に置き換える。優先順は上から。

| 優先 | 表示 | 例 | 備考 |
|---|---|---|---|
| 1 | **シリーズ名 + マスター内の位置** | `♪ AFTERNOON #01　03:15〜` | 事実のみ。視聴者が本編で同じ場所を探せる。固定コメントのタイムスタンプとも一致する。**推奨** |
| 2 | **歌詞の英語1行** | `♪ "…"` | 歌い出しの1行を耳で書き起こす。曲名の代わりに雰囲気を伝える。自信がない語は載せない（誤記を避ける） |
| 3 | **曲名行を非表示** | 署名「舞」だけ右端に残す | 情景コピー（主テロップ）だけで成立させる最終手段 |
| 追加 | **後付けの曲名を新しく付ける** | `Afternoon Sketch 01` など | 原題は失われているので、#01 の概要欄にタイムスタンプ+新しい曲名を追記する運用とセットにするなら可。付けた名前は以後固定し、Shortsと概要欄で食い違わせない（D2/D4の誠実性） |

- 副テロップの [歌詞] 型は、優先2と併用せず、どちらか一方にする（画面が重くなるため）。
- 主テロップ（情景一行）と副テロップ（[用途]/[問い]）は標準形のまま使える。曲名に依存しないため、差替えで書き換える必要はない。

### 8.5 判断フロー
```
B1: マスターは手元にあるか
 ├─ ある → 8.2 の5本を差替え → 標準形の「2回使用」は #02 の単発15本に
 │         （切り出し前に、マスターの-16LUFS正規化と継ぎ目の位置を確認）
 └─ ない → 標準形（§2）で運行。2回使用の効果は §5.3 の追加観察で測る
```
